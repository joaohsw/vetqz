Engenharia de Software COIL UFSM × UST

Arquitetura, tecnologias e escolhas técnicas

Frontend

React 19 · Vite · TailwindCSS

  • Gravação e transcrição de voz no navegador
  • Interface bilíngue (PT-BR / ES-CL)
  • Upload direto via protocolo TUS (até 50 MB)

Backend API

Python · FastAPI (Vercel)

  • Extração e chunking conservador de PDFs
  • Delimitadores XML contra prompt injection
  • Gabarito determinístico na múltipla escolha

Dados & IA

Supabase · Gemini 3.5 Flash-Lite

  • PostgreSQL com RLS e retenção de 7 dias
  • Cache bilíngue único por hash SHA-256
  • Feedback com página original do PDF

Desafios e aprendizados

Principais desafios

  • Tratar PDFs extensos dentro do limite serverless (solução: upload TUS direto ao Storage).
  • Limpar ruídos do texto sem quebrar termos compostos anatômicos.
  • Manter consistência de notas/métricas entre sessão ativa e histórico.
  • Localizar fluxos e mensagens de erro para espanhol chileno (es-CL).

Aprendizados da parceria

  • Testar cedo com usuários reais muda prioridades técnicas (ex.: múltipla escolha).
  • Tradução de necessidades entre Computação e Medicina Veterinária.
  • Colaboração interdisciplinar e comunicação internacional contínua.
